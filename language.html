1. Language guide

QG is a compact game language. The compiler converts its instructions into binary opcodes and reconstructs JavaScript using a shared browser runtime.

Variables and arithmetic 
let x = 10;
let y = 20;
x = x + 1;
y = x * 2;

Supported operators: + - * / % < > == != <= >=. Variables are stored using 6-bit IDs.

Drawing 
canvas(240,320);
clear();
rect(10,20,40,30,1);

canvas(width,height) sets the canvas size. rect(x,y,width,height,color) draws a rectangle. Colors are numbered 0–7 in this prototype.

Conditions 
if(x > 100){
  x = 0;
}else{
  x = x + 1;
}
Loops 
for(let i=0;i<10;i=i+1){
  rect(i*20,40,10,10,2);
}

This prototype executes loops when the game starts. Animation loops will be added in a later version.

Current limitations

This version supports integer literals, variables, assignments, drawing, conditions and counting loops. Functions, sprites, arrays, events, floating-point literals, and animation callbacks are not implemented yet. It uses a fixed experimental opcode table.
