5. Sprite sheets

Sprites are stored as rectangular grids of digits.
      Every row must have the same width.
      Each digit is a palette index from 0 to 4:
      zero is transparent and 1–4 are visible colors.
      Sprites can be any supported rectangular size,
      including 8×8 and 16×16.

CODE EXAMPLE:
palette ivory=[
  null,
  "#ead4b6",
  "#55483e"
];

sprite pawn(ivory){
00011000
00111100
00111100
00011000
00111100
01111110
01111110
12222221
}

blit(pawn,20,20,5);

The blit arguments are sprite, X position, Y position,
      and scale. An 8×8 sprite drawn at scale 5 occupies
      40×40 logical pixels.

The compiler compares base-5 pixel packing with
      run-length encoding and uses the smaller representation.
      This is especially effective for sprites with large
      transparent regions or repeated colors.
